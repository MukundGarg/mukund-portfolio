# Mukund Garg Portfolio

A custom Next.js portfolio inspired by the interaction language of modern dark bento portfolios, built specifically around Mukund Garg's AI/ML, backend, automation, and computer-vision work.

## Stack
- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.

## Deploy
Push to GitHub and import the repository into Vercel. No environment variables are required for this static version.

## Customize
- Portfolio content: `lib/portfolio-data.ts`
- Page composition and motion: `components/portfolio.tsx`
- Visual system: `app/globals.css`
- Resume download: `public/resume.pdf`
